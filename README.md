# Portfolio

PortfolioPro is a modern full-stack portfolio website that allows developers to showcase their skills, projects, certificates, education, and experience through a professional and responsive user interface.

## Features

* Responsive Portfolio Website
* Admin Authentication (JWT)
* Project Management System
* Certificate Management
* Contact Form
* MongoDB Database Integration
* Dark / Light Theme
* Project Search Functionality
* Resume Download
* Education & Experience Timeline
* Modern Glassmorphism UI

## Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Authentication

* JWT (JSON Web Token)

## Installation

```bash
npm install
npm run dev
```

Create a `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
```

Open:

```text
http://localhost:5000
```
